# 訴願快速拆解平台（Demo 原型）

一個給法制局使用的五步驟訴願拆解工作台，白色為主、深藍色為輔（navbar／重點按鈕）。全站使用您提供的洗錢防制法案件（案號 1147101471、訴願人 林○如、原處分機關 新北市政府警察局蘆洲分局）作為示範資料，AI 判讀內容以寫死的示範資料呈現，不需登入或後端。

## 五個步驟

### 步驟一：訴願資格初判（四象限分類）
- 頁面分四象限：AI 判讀高風險失格 / AI 判讀過關 / 人類確認過關 / 人類確認失格。
- 每張案件卡片為文件 icon + 案件名稱，可用滑鼠拖曳到任一象限。
- 點開案件 → 全螢幕檢視：左側原始文件全文（可捲動、AI 重點句以黃色高亮），右側 AI 判讀結果卡片。左側高亮與右側對應理由以 SVG 連線串接，滑過會強調。
- 判讀重點固定五項：原處分機關、案件分署（廢清法／洗錢防制法／空污法）、送達程序、法定期間內提出、先行程序（原機關是否答辯）。本案重點：逾期 678 日 → 高風險失格。
- 右下角「人工審核」：同意 AI 判讀 → 進入下一步；不同意 → 需填寫原因並提示拖曳到對應象限。
- 只有落在「人類確認過關」象限的案件能進入步驟二；未通過的案件點開顯示「流程等待確認」。

### 步驟二：事實與爭點整理
- 左：AI 整理的訴願事實；右：AI 整理的答辯理由，各自可點開閱讀原始文件。
- 上方為爭點關鍵句按鈕列（例：是否逾 30 日法定期間、僅告知帳號是否構成「交付、提供他人使用」、不起訴處分是否為新證據）。點擊後左右兩側對應語句高亮並自動捲動。
- 下方兩個按鈕：人工新增爭點（開啟表單）、完成爭點整理 → 下一步。

### 步驟三：訴願決定與資料援引
- 說明文字：依事實與爭點，AI 建議三個相關法條與三個相似案例。
- 左欄：上半訴願事實、下半答辯理由。
- 右欄：上半建議法條（訴願法第 14 條、第 77 條第 2 款、洗錢防制法第 22 條，附全國法規資料庫超連結），下半相似案例（北高行 114 年度簡上字第 13 號等，摘要可展開／另開分頁）。
- 下方按鈕：人工新增參考資料、進入下一步。

### 步驟四：決定文草擬
- 左：可編輯的決定文草稿，含案號／要旨／發文日期／發文字號／相關法條／全文（新北市政府訴願決定書格式、主文、理由），預先帶入本案內容。
- 右：AI 判斷之依據，分區塊呈現「原始訴願書重點／答辯書重點／法條編輯（超連結）／相似案例編輯（超連結）／AI 綜合判斷（結論）」，每區塊可編輯，並可「新增參考依據」。
- 右下角：將草稿存入庫存。

### 步驟五：草稿庫存與送交委員會
- 庫存列表（案號、訴願人、狀態、更新時間），可預覽草稿全文、下載為文字檔、送交委員會；送交後標記為「已送交委員會」。

## 全域介面
- 深藍 navbar，含五步驟進度指示（步驟一完成才可前進）。
- 步驟二起，畫面左上恆常顯示「訴願人 林○如 ・ 案號 1147101471」。

## 技術重點
- TanStack Start 路由：`/`（步驟一）、`/step2`…`/step5`；共用 layout 提供 navbar 與步驟列。
- 全站狀態（案件象限、審核意見、爭點、草稿、庫存）放在 React context + sessionStorage，重整不遺失；不啟用後端。
- 示範資料集中在 `src/data/` （案件、文件全文段落、AI 重點句與座標錨點、法條與案例）。
- 高亮連線用一個 SVG overlay 元件，依 DOM 量測畫貝茲曲線，視窗縮放時重算。
- 拖曳使用原生 HTML5 drag and drop，不加套件。
- 設計 token 寫在 `src/styles.css`（白底、深藍 primary、細邊框、無紫色漸層），字體採黑體系中文字型堆疊。
