# 「我的案件」案件處理中心 popup 設計

日期：2026-09-11  
範圍：`frontend` 純前端 PC 版

## 目標

將目前併排在案件佇列右側的「案件處理中心」改為置中的 popup，讓案件佇列在所有狀態下維持滿版，並保留既有案件處理內容與互動流程。

## 核准方案

- 點擊案件列後，以現有 Radix `Dialog` 元件開啟「案件處理中心」popup。
- popup 顯示目前選取案件的完整處理中心內容，包含補正／補卷流程、案件進入動作與文件判讀依據入口。
- 關閉 popup、點擊右上角關閉按鈕或遮罩時，清除案件選取狀態。
- 案件佇列不再因選取案件而切換成左佇列／右面板配置，始終使用滿版寬度。
- 「查看文件與 AI 判讀依據」維持既有獨立 Dialog，不變更其內容。
- 不變更案件資料、篩選、排序、流程狀態及手機版專屬樣式。

## 資料流與互動

- `selectedId` 同時作為目前案件與處理中心 Dialog 的開關來源。
- 案件列選取後設定 `selectedId`；React 更新後顯示對應案件 popup。
- 搜尋／篩選使選取案件離開結果時，沿用既有規則清除 `selectedId`，popup 隨之關閉。
- popup 關閉事件設定 `selectedId` 為 `null`，避免保留不可見的選取狀態。

## 驗收條件

- 初始畫面只顯示滿版案件佇列，不顯示右側處理中心。
- 點擊案件列後，置中顯示「案件處理中心」popup，內容對應該案件。
- popup 關閉後回到滿版案件佇列。
- 案件處理中心內的既有按鈕、補件流程及文件判讀入口仍可使用。
- `index.tsx` ESLint 與專案 build 通過。
